🚀 Extension Setup Instructions

Step 1: Load Extension in Chrome

  1. Open Chrome and go to chrome://extensions/
  2. Enable "Developer mode" (top right toggle)
  3. Click "Load unpacked"
  4. Select the folder: C:\Users\User\RVISED3\extensions\rvised-extension
  5. The extension should appear in your extensions list

Expected Flow:

  1. Extension loads on YouTube page ✓
  2. Rvised button appears in sidebar ✓
  3. Click "Summarize" button
  4. Extension sends request to http://localhost:3003/api/summarize
  5. API uses YTX to extract transcript
  6. API sends transcript to OpenAI for summarization
  7. Summary appears in extension UI

Common Issues & Fixes:

  • Extension not showing: Reload extension in chrome://extensions/
  • API not reachable: Ensure server is running: cd rvised && npm run dev
  • YTX fails: Check that Python and YTX are installed correctly
  • CORS errors: API should have CORS headers configured (already done)
