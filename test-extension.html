🎓 Rvised Chrome Extension - Test & Setup Guide

Follow these steps to load and test the Rvised extension with the new UI

📋 Setup Instructions

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" toggle in the top right corner
  3. Click "Load unpacked" button
  4. Navigate to and select: C:\Users\User\RVISED3\extensions\rvised-extension
  5. The extension should now appear in your extensions list
  6. Open a YouTube video to test the extension

✅ Extension Features Checklist

  • 1 Extension loads on YouTube: The Rvised overlay should appear in the right sidebar
  • 2 UI Components: Header with logo, tabs (Summary, Transcript, Dashboard), and settings
  • 3 Mode Selection: Can switch between Student, Build, and Deep modes
  • 4 Depth Selection: Can choose Quick, Standard, or Detailed summaries
  • 5 Options Menu: Dropdown with Timestamps, Quiz, and Transcript toggles
  • 6 Summarize Button: Blue button that triggers video analysis
  • 7 Settings Screen: Opens when clicking the settings icon
  • 8 Create Project: Can create new projects for organizing summaries
  • 9 Save Summary: Saves the generated summary to selected project
  • 10 Timestamp Navigation: Clicking timestamps jumps to that video position

🔍 What to Test

  1. Initial Load: Extension should auto-show when you navigate to a YouTube video
  2. Summarize: Click "Summarize video" and wait for the analysis to complete
  3. View Tabs: Switch between Summary, Transcript, and Dashboard tabs
  4. Settings: Open settings, change modes and options, then apply
  5. Quiz: If enabled in options, quiz questions should appear after summary
  6. Project Creation: Click "+ Create" to add a new project
  7. Save to Project: Select a project and save the summary

⚠️ Common Issues & Solutions

  • Extension not showing: Refresh the YouTube page after loading the extension
  • UI looks broken: Check browser console for errors (F12 → Console tab)
  • Summarize fails: Ensure the backend API is running (check localhost:3000)
  • Icons missing: Verify icons folder exists in the extension directory
