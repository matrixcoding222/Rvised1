🚀 Stripe Setup Helper

Complete your Rvised payment integration

✅ Step 1: Your API Keys (Already Set)

Great! Your Stripe API keys are already configured in .env.local

📦 Step 2: Create Products in Stripe Dashboard

1. Go to your Stripe Dashboard

Open Stripe Products (Test Mode) →

2. Create these two products:

Product 1: Monthly Subscription

Name: Rvised Pro Monthly Price: $7.99 Billing: Recurring / Monthly

Product 2: Annual Subscription

Name: Rvised Pro Annual Price: $47.88 Billing: Recurring / Yearly Description: Save 50% with annual billing

3. After creating each product, copy the Price ID

The Price ID looks like: price_1AbCdEfGhIjKlMnOp

🔑 Step 3: Enter Your Price IDs

🔄 Step 4: Set Up Webhook (For Local Testing)

1. Download Stripe CLI

Download Stripe CLI for Windows →

2. Open Terminal/Command Prompt and run:

stripe login stripe listen --forward-to localhost:3000/api/webhooks/stripe

This will give you a webhook secret starting with whsec_
